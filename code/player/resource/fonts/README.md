The player embeds this font so Latin and CJK filenames use the same glyphs
and metrics on Windows and Linux.

- `NotoSansCJKsc-Regular.otf`: unmodified Simplified Chinese face exported from
  Noto Sans CJK Regular 2.004's TTC, copyright Adobe (2014–2021).
  See `LICENSE-NotoSansCJK.txt` (SIL Open Font License 1.1).

The original font metadata, glyphs and naming are preserved. The font is
loaded from Qt resources; users do not need to install them system-wide.
